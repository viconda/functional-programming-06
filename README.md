Выполнены 16 примеров лекции, четыре задания СРС по функциональной СУБД,

вопросы находятся в двух отдельных отчётах.

## Запуск

Python 3.10 или новее. Для алгоритмов достаточно стандартной библиотеки.

```text
python demo_lecture.py
python demo_algorithms.py
python demo_trees.py
python -m unittest discover -s tests -v
```

Каждый подпункт можно запустить отдельно, например:

```text
python demo_lecture.py --section E01
python demo_algorithms.py --section L4c
python demo_trees.py --section L7
```

## Состав

- `lecture06/` — примеры лекции и функциональная СУБД.
- `lab06/` — алгоритмы, вложенные структуры, BST, перебор, файловая модель,
  родословная и AVL.
- `tests/` — автоматические проверки и независимые контрольные алгоритмы.
- `data/nested.json` — JSON для задания 2.
- `reports/` — отдельные отчёты Word по лекции и лабораторной работе.
- `evidence/` — снимки настоящих запусков программ.
- `verification/` — журналы тестов и исходные результаты запусков.
- `recursion06_history.bundle` — локальная история Git, которую можно
  восстановить командой `git clone recursion06_history.bundle recursion06`.

Данные о студентах, оценках и родственниках вымышлены и используются для
проверки алгоритмов. Снимки получены в локальной оболочке запуска Python,
показывающей stdout отдельного процесса. Замеры времени относятся к
конкретному компьютеру; при повторном запуске секунды могут отличаться.
