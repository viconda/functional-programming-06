Функциональное программирование CSE6742
Работа 06. Рекурсия
Швачкина Виктория, группа CSE6742onl, вариант 3

Комплект содержит два самостоятельных отчёта: лекцию и лабораторную.
Python 3.10 или новее. Вычислительные модули используют стандартную библиотеку.

Запуски из каталога проекта:
python demo_lecture.py
python demo_algorithms.py
python demo_trees.py
python -m unittest discover -s tests -v

Отдельный пример:
python demo_lecture.py --section E01

lab06 содержит модули dc, nested, bst, backtracking, fs_tree,
genealogy и avl. Индивидуальное задание выполнено по варианту 3.
В lecture06 находятся примеры лекции и функциональная СУБД.
В data сохранён настоящий JSON-файл для проверки вложенных структур.

Папка evidence содержит снимки настоящих запусков. В verification/runs
сохранены команды, время запуска, stdout, stderr и код завершения.
Снимки получены в локальной оболочке запуска Python, которая запускает
отдельный процесс демонстрации и отображает его вывод без подмены.

Замеры времени зависят от компьютера и текущей нагрузки. Проверки
сравнивают результаты алгоритмов, а не требуют совпадения времени.
Данные о студентах, оценках, родственниках и файлах в примерах учебные.
